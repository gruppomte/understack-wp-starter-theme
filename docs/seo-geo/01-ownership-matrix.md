# SEO/GEO Foundation — Phase 0: Ownership Matrix

Who is responsible for each signal in each supported situation. "Theme" means the SEO/GEO foundation proposed in `02-implementation-plan.md`; "silent" means the theme emits nothing for that signal.

## 1. Resolution rules

1. **Core first.** Whatever WordPress core already emits is kept and extended through its filters; the theme never prints a competing tag.
2. **Provider wins.** When a supported SEO plugin is detected, the theme is silent for every signal the provider owns (title, description, canonical, robots directives beyond the environment policy, social metadata, structured data graph, sitemap, `robots.txt` body, breadcrumb data). Per-signal overrides exist only as explicit configuration and default to off.
3. **Fallback only when nobody else does it.** Without a provider the theme fills the gaps listed below with data that already exists (content, excerpt, featured image, site name, configured entity) and omits anything it cannot derive from real data.
4. **Environment policy is always the theme's.** `noindex, nofollow` on non-production environments is added regardless of the provider, because providers cannot know the deployment topology; it is driven by explicit configuration (`WP_ENVIRONMENT_TYPE` or a declared host list), never by heuristics. Delivery follows the provider: core's `wp_robots` filter with no provider or with Yoast (which merges into it), `rank_math/frontend/robots` with Rank Math (which clears the `wp_robots` chain and prints its own tag), plus an `X-Robots-Tag` response header in every case.
5. **Infrastructure stays outside.** HTTP authentication on staging, `X-Robots-Tag` headers, WAF and CDN bot rules, redirects at the edge, TLS and host canonicalisation are documented as checklists, not simulated.

## 2. Provider detection

| Provider          | Detection (any of)                                                                     | Status in this project                                                                    |
| ----------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Rank Math         | `defined('RANK_MATH_VERSION')`, `class_exists('RankMath')`                             | Measured locally (1.0.280). Front end dormant until registration is skipped or completed. |
| Yoast SEO         | `defined('WPSEO_VERSION')`, `function_exists('YoastSEO')`                              | Measured locally (28.6).                                                                  |
| SEOPress          | `defined('SEOPRESS_VERSION')`                                                          | Detection only; treated as a full provider; not measured.                                 |
| All in One SEO    | `defined('AIOSEO_VERSION')`                                                            | Detection only; not measured.                                                             |
| The SEO Framework | `defined('THE_SEO_FRAMEWORK_VERSION')`                                                 | Detection only; not measured.                                                             |
| Slim SEO          | `defined('SLIM_SEO_VER')`                                                              | Detection only; not measured.                                                             |
| Unknown plugin    | Head output contains a second canonical or JSON-LD after the theme would print its own | Diagnostics warn; configuration can force "provider present".                             |

Detection is evaluated once per request at `wp` priority late, cached in memory, and overridable through a filter so a site can force either state.

## 4. Multilingual (WPML) and e-commerce (WooCommerce)

| Signal                         | WPML present                                                                                                                                                       | WooCommerce present                                                                                                                                     |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| hreflang / language alternates | WPML                                                                                                                                                               | —                                                                                                                                                       |
| Canonical per language         | Provider or theme fallback using the current language permalink (WPML filters `home_url`/permalinks); theme must not hardcode `home_url()` of the default language | Provider or theme fallback; cart, checkout, account pages excluded (WooCommerce marks them `noindex` through `wp_robots`; to verify locally in Phase 7) |
| `x-default`                    | Only when WPML is configured with a default language and the project decides so; theme silent otherwise                                                            | —                                                                                                                                                       |
| Entity URLs and breadcrumbs    | Localised through WPML permalink filters; strings translated with the theme text domain                                                                            | Product category trail from WooCommerce breadcrumbs when present                                                                                        |
| Structured data                | Theme graph localised per request; `inLanguage` from `get_locale()`                                                                                                | Product/Offer from WooCommerce; theme never emits Product                                                                                               |
| Sitemap                        | WPML adapts core or provider sitemap                                                                                                                               | WooCommerce adds product types to core sitemaps                                                                                                         |

Both integrations are designed against documented hooks and will be marked "not certified" until tested on a site that has the plugin.

## 5. Configuration ownership (what the client must provide)

| Data                                                                                                                                                                        | Where it will live                                                                            | Default when missing                                   |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| Entity type (Organization / LocalBusiness subtype), legal name, logo, public contact points, postal address, geo, opening hours, areas served, official profiles (`sameAs`) | ACF "Site Settings" options page (new tab, versioned in `acf-json`) with validation on read   | No `Organization`/`LocalBusiness` node; `WebSite` only |
| Default social image                                                                                                                                                        | Same options page                                                                             | No `og:image`                                          |
| Environment declaration                                                                                                                                                     | `WP_ENVIRONMENT_TYPE` in `wp-config.php`; optional declared production hosts through a filter | Policy inactive (no `noindex`); diagnostics warn       |
| Crawler policy                                                                                                                                                              | Code configuration (filter) per project                                                       | Empty (core `robots.txt` untouched)                    |
| Feature overrides when a provider is active                                                                                                                                 | Code configuration (filter)                                                                   | All off                                                |
| Author profiles                                                                                                                                                             | Existing user profiles (display name, description, URL)                                       | `Person` omitted unless enabled                        |

Nothing in the above is pre-filled with agency or placeholder data.
